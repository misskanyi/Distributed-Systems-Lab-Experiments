## Repository Overview

Five standalone distributed systems lab assignments, each in its own folder. They are independent of each other and progressively introduce different paradigms: raw sockets → RMI → CORBA → MPI → clock synchronization.

| Assignment | Tech | Language |
|---|---|---|
| 1 | TCP Socket chat | Java |
| 2 | Java RMI (Remote Method Invocation) | Java |
| 3 | CORBA calculator | Java + IDL |
| 4 | MPI (Message Passing Interface) | Java (MPJ Express) |
| 5 | Berkeley Clock Synchronization | Python |

## Build & Run Commands

### Assignment 1 — TCP Socket Chat
```bash
cd "Assignment 1"
javac MyServer.java MyClient.java
# Terminal 1 (server first):
java MyServer
# Terminal 2:
java MyClient
```
Type `bye` on either side to end the session. Uses port **5555**.

### Assignment 2 — Java RMI
```bash
cd "Assignment 2"
javac ServerInterface.java Servant.java Server.java Client.java
# Terminal 1:
rmiregistry &
java Server
# Terminal 2:
java Client
```

### Assignment 3 — CORBA Calculator
Uses Maven with the GlassFish CORBA ORB dependency (Java 17).
```bash
cd "Assignment 3"
# Regenerate IDL stubs (only needed if Calculator.idl changes):
idlj -fall Calculator.idl
# Build:
mvn compile
# Terminal 1 — start the ORB name service:
orbd -ORBInitialPort 1050 &
# Terminal 2 — server:
java -cp target/classes:$(cat cp.txt) StartServer -ORBInitialPort 1050 -ORBInitialHost localhost
# Terminal 3 — client:
java -cp target/classes:$(cat cp.txt) StartClient -ORBInitialPort 1050 -ORBInitialHost localhost
```
`cp.txt` contains the Maven dependency classpath (generated by `mvn dependency:build-classpath -Dmdep.outputFile=cp.txt`).

The IDL-generated stubs live in `Calculator/` — do not edit them by hand.

The `CalcObject.java` is the servant implementation; `StartServer.java` registers it with the ORB naming service; `StartClient.java` looks it up and calls `calculate(opcode, op1, op2)` where opcode 1=add, 2=sub, 3=mul, 4=div.

### Assignment 4 — MPI Hello World
Requires MPJ Express (or equivalent MPI-for-Java library) installed and `MPJ_HOME` set.
```bash
cd "Assignment 4"
javac -cp $MPJ_HOME/lib/mpj.jar HelloWorld.java
mpirun -np 4 java -cp .:$MPJ_HOME/lib/mpj.jar HelloWorld
```
Process 0 is the master; all other ranks send a message to rank 0.

### Assignment 5 — Berkeley Clock Synchronization (Python)
No dependencies beyond the Python standard library.
```bash
cd "Assignment 5"
# Terminal 1 — master server:
python3 Server.py
# Terminal 2+ — one or more slave clients:
python3 Client.py
```
Server listens on port **2050**. Clients send their local time every 5 s; server computes the average clock difference and pushes back a synchronized time to all connected clients.

## Architecture Notes

**Assignment 3 CORBA flow:**
1. `Calculator.idl` → `idlj` → generated files in `Calculator/` (stubs, POA skeleton, helpers)
2. `CalcObject` extends `Calculator.CalcPOA` and provides the real arithmetic
3. `StartServer` binds the servant to the ORB naming service; `StartClient` resolves the name and invokes methods through the generated `_CalcStub`
4. `orb.db/` is the ORB's persistent naming-service database — do not delete it while the ORB daemon is running

**Assignment 5 clock sync flow:**
- Each client thread in `Server.py` records `(client_clock_time, time_difference)` keyed by address
- A separate synchronization thread averages all deltas and broadcasts `now + average_delta` back to every connected client every 5 s (Berkeley algorithm approximation)
