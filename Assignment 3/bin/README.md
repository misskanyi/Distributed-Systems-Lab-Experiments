# Assignment 3 — CORBA Calculator

A calculator server exposed via CORBA/IIOP, defined with an IDL interface and
invoked by a client through the ORB naming service.

## Files
| File / Dir | Role |
|---|---|
| `Calculator.idl` | IDL interface: `calculate(opcode, op1, op2)`, `exit()` |
| `Calculator/` | Stubs/skeletons generated by `idlj` — do not hand-edit |
| `CalcObject.java` | Servant implementation (extends `CalcPOA`) |
| `StartServer.java` | Registers the servant with the ORB naming service |
| `StartClient.java` | Looks up the servant and invokes `calculate` |
| `pom.xml` | Maven build (GlassFish CORBA ORB dependency, Java 17) |
| `cp.txt` | Maven dependency classpath (generated, used at runtime) |
| `orb.db/` | ORB's persistent naming-service database — don't delete while `orbd` is running |

## How to Run
```bash
cd "Assignment 3"
# Only if Calculator.idl changes:
idlj -fall Calculator.idl

mvn compile

# Terminal 1 — ORB naming service
orbd -ORBInitialPort 1050 &

# Terminal 2 — server
java -cp target/classes:$(cat cp.txt) StartServer -ORBInitialPort 1050 -ORBInitialHost localhost

# Terminal 3 — client
java -cp target/classes:$(cat cp.txt) StartClient -ORBInitialPort 1050 -ORBInitialHost localhost
```
Client prompts for `[operator] [operand1] [operand2]`, e.g. `+ 1 2`. Opcode
mapping: `1`=add, `2`=sub, `3`=mul, `4`=div. Type `exit` to shut down the ORB.

## Key Concepts
- **IDL** — language-neutral interface definition compiled to Java stubs/skeletons.
- **POA (Portable Object Adapter)** — connects incoming requests to the servant.
- **Naming Service** — CORBA's directory for looking up remote object references by name.
- **IIOP** — the wire protocol ORBs use to talk to each other across languages.
